# Image handoff

Confirm one reference image with the user before making dependent images.
Keep character identity, wardrobe, palette and medium consistent. Leave readable space for bottom-center lyrics.
Copy images under the project directory and register local relative paths, SHA-256 and actual pixel dimensions in assets.json.
Record reference_asset_ids and available generator/model/settings. Never store API keys or signed URLs.
Generated and imported images share the same assets schema. Automatic paid generation is outside this version.
