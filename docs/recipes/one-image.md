# 一枚の画像から動画（レシピ）

一枚の画像から短い動画を作るだけなら、このレシピと `plan.md` で足りる（MV 用のスキル orpheus-mv-build と README は読まなくてよい。`docs/fx.md` は部品を足すときだけ、その節を読む）。`mv fx quick` は実験的で、確かめたのは合成の絵だけ。

守ること（MV 用のスキルから、一枚絵に要るものだけ）:
- technical_pass（機械の検査）と採否を分けて書く。採否は依頼した人が決める。
- 推定は推定と書く（目盛りで読んだ点・見た目の判断は実測ではない）。素材と動画は Git に入れない。

## 流れ

1. **点を読む**: `uv run mv fx guides IMAGE --out grid.jpg --brief`。`grid.jpg` の目盛りで、顔か目（寄り）・腕や道などの線・山場の点を 0..1 で読む。点はどれも任意。
2. **型を決める**: 静かな絵（山場の無い絵）には `--impact` を付けない（静かな型: 閃光・輪・火花・揺れを使わず、寄りの点にやわらかい光が差して薄れる）。山場の点が地面でなければ、`hooks.py` の `RING = 0`（輪は地面を走る）。
3. **一式と下見**（点は横長の絵の例）:
   ```sh
   uv run mv fx quick IMAGE OUT --focus 0.30,0.35 --path 0.20,0.70:0.70,0.40 --impact 0.72,0.38 --preview
   ```
   stdout は数行（全部の値は `--json`）。`OUT/preview.jpg`（半分の大きさのコマの一覧）を 1 枚見る。
4. **直す**: `plan.md` の表のとおり、変える引数だけ書いてやり直す（前の値を引き継ぐ。点を外すときは `none`）。大きさは `plan.md` の「寄りの上限」の行で 1 回で決める（例: 1920x1080 で 1.25 倍しか寄れない絵は、1280x720 なら 1.88 倍）。何通りも描いて比べない。
5. **本番と確認**: `uv run mv fx quick IMAGE OUT --render`。描いた後に `OUT/check.jpg`（頭・一番寄った所・山場か真ん中・終わりのコマと、一番寄ったコマの等倍・元画像の同じ所）と要約（寄りの最大・明滅・顔の切れ・元画像との差・止まったコマ）が出る。確認はこれを見るだけでよい（自前の検査コードは書かない）。`mv inspect check OUT/inspect.json --brief` は任意。
6. **記録**: `OUT/log.md` に実行のたびに引数・注意・所要時間・出力のパスが足される。作業記録はこれを参照してよい（採否は人が書き足す）。

かかった時間（2 コアのコンテナ、横長の合成の絵 1600x900 → 1920x1080・12 秒・288 コマ。2026-11-28 に測った）: 一式と下見 1 秒未満、本番と確認 45 秒ほど。

## 罠

- **寄りの倍率**: 元画像の 1 画素を画面の 1.5 画素まで（超える `--zoom` は止めて `warnings`）。切り出して拡大した画像を元にしない。カメラは `frame: source`・`plate: full`。
- **カメラ**: キーは `camera.curve: smooth`（速さが続く曲線）でつなぐ。止まらず、向きも急に返さない。キーを手で足すなら同じ形のまま（止めて長く置くと `mv inspect` の「止まったコマ」に出る）。
- **顔が端で切れる**: 寄りの点のまわり（既定は短い辺の 0.075 の半径。`--focus-radius`）が端で切れたまま 0.4 秒を超える段があると、quick は形を変えて収め、収まらなければ `warnings` と `plan.md` に直し方を書く。
- **線が届かない**: `--path` の端がカメラの届かない所にあると、線の上の届く所へ移して `warnings` に書く。
- **閃光**: 山場の 1 回だけ（1 秒に 3 回まで）。強さは山場の画面の明るさから決める。部品を足したら確認の「明滅」を見る。
- **クロスフェードの二重写し**: 同じ絵の違う寄りを `xfade` でつながない（1 本のカメラで動かすか、カット）。
- **透かし**: 元画像のロゴ・署名・生成サービスの印を消したり隠したりしない。端の透かしが切れて気になるときはユーザーに聞く。
- **手で直したファイル**: 違う引数でやり直すと止まる（`--force` で上書き）。やり直しで変わるのは `hooks.py` の定数の値だけで、任意の行は同じ置き換えで戻せる。

## 部品を足すとき

- 山場の部品は `mv_pipeline.fx.impact`（火花・衝撃の輪・閃光・揺れ・点の閃き・暗転）、静かな型の光は `accent.warm_light`。長さは幅 1920 の画素で書き、`k=view.px` を渡す。
- 火・空・明かりの部品は `docs/fx.md` の「演出の hooks」の節だけを読む。部品に無いものを自前で書く前に `docs/external-renderer.md`。
