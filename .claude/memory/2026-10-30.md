### Design Decisions

- **SAC は切らない**: 一度切ると戻せないため。署名つきの Python を使えば、署名の無い拡張モジュール（numpy・OpenCV など）は通ることを実測で確かめた。
- **PC での実行は `python -m mv_pipeline.cli`**: `uv run mv` と `.venv\Scripts\mv.exe` は uv が作る署名なしの起動ファイルを通るため使わない。テストも `python -m pytest`。
- **uv sync は `UV_PYTHON_DOWNLOADS=never` と `--python <署名つき Python>` を必ず付ける**: 付けないと署名なしの Python を取りに行く恐れがある。
- **公開版の設定のうち fx の look に無い要素**: この区間では粒子（既定 0.30）と歌詞テロップの合成（光の滲み・影）だけ。稲光の閃光と拍の拡大は盛り上がり区間にしか出ないので効いていない。
