## Phase

ロードマップ（`docs/roadmap.md`）の段階 0（安全網と演出エンジン fx v0.1、PR #2・#6）に続き、段階 1 を公開済みの第 1 作の 1 カットで実施し、ユーザーが both 版を採用した（2026-10-30 に PC で `fx accept` を記録済み）。段階 1 の課題だった色調整・周辺減光・粒状感は fx の `look` として PR #9 で足し、2026-10-30 に段階 2 の Part A として、段階 1 のカットに公開版の調色（`grade_keys` 11 キー）と既定の減光・粒を当てた 4 版を描いて公開版と並べた（全版 technical_pass、ユーザーの判定待ち）。判定の後、ユーザーの了承で Part B（同じ作品の別カットに設定変更だけで当てる）に進む。PC は Windows のスマート アプリ コントロールが有効なため、.venv を署名つき Python で作ってある（手順は `docs/dependencies.md`）。2026-10-31 にユーザーの資料をもとに、ダンス合成 `mv dance`（PR #11）と、書き出し前の機械的な検査と行・秒の確認表 `mv gate`（PR #12。AGENTS.md の裁定の例外としてユーザーが承認）を足し、続けて設定を `dance-shot/0.2` に広げた（PR #14〜#18）。ユーザーの素材で縦のダンス動画を 3 本作り（コードの変更なし）、見つかった色の読み違いを PR #21 で直した。2026-11-01〜02 はリポジトリの外で、動画から推定した動きを 3D キャラに載せる試作を進めている（DANCE-3D-1）。並行トラック（工程の骨格の実害修正）は未着手で、判断ゲート（統合／併存／Remotion 進化、実制作ツールの取り込みの可否）は段階 2 の後に置く。
