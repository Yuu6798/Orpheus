### Design Decisions

- **入口は GPT 案、足回りは Claude 案**: 表現（生成側）から入り、同じ素材・同じ 10 秒の 4 版比較で効果を見せる。安全網・道具の退避・判断ゲート・撤退条件は Claude 案から。2026-09-10 裁定（生成→実測→検証→修正→再生成、生成物の開発中は測定器・検証器へ機能を足さない）に合わせた。
- **実制作ツールは取り込まない**: public のため。代わりに `mv fx legacy`（手元のレンダラのパスを渡して呼び、sha256・逐次ログ・出力検査を run に残す）で接続する。取り込むかは判断ゲートで public/private と合わせて決める。
- **fx は Python/OpenCV で実装し、Remotion は保守凍結**: 実制作と同じ系統（CPU・決定論）。Remotion は判断ゲートまで新機能を足さない。
- **新設定は contracts/ の外**: `fx-shot/0.1` は `src/mv_pipeline/fx/fx_shot.schema.json`。既存 3 契約は 1 バイトも変えていない。昇格はユーザー承認。
- **座標は元画像の正規化座標**（光の位置・半径・光点の大きさ・カメラ中心）。出力の縦横比を変えても光が対象に付いたまま動く。
- **派生ズームは対数空間** `z0·(zoom/z0)^p`: 線形式はズームアウトで p>1 の層が 0 や負のスケールになるため（Codex 指摘）。
- **局所性と決定論をテストで固定**: 受光マスクの外かつ光点の影響半径の外の画素は、光なしの版とビット一致する。同じ spec・seed ならフレームのバイトが一致する。
- **見送り（境界宣言）**: 画面外警告を parallax≠1・drift・深度変位へ広げる件、light 版の光点の深度追従、推移依存の exclude-newer。いずれも検証側の機能追加や再修正の連鎖にあたるため、次の周回の材料にした（各コミット本文に理由）。
- **svp から取り入れたもの / 取り入れないもの**: 取り入れたのは CI（SHA 固定・最小権限）・pip-audit・Dependabot・uv 版固定（さらに `required-version` で強制）・外部境界の密閉テスト。取り入れないのは規律層の重い部分（discipline テスト・Design Memo 書式）、planner の正規表現・semantic repair、課金ジョブを kill して ID を失う設計、縦横比の黙った強制。今回の `.claude/memory/` 導入はユーザー依頼による最小移植（wrap-up 手順は Orpheus 向けに短縮、discipline テストは未移植）。
