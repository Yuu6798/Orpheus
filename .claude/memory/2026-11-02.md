### Design Decisions

- **色の読み方は環境で違う**: Windows の OpenCV 5.0.0 は BT.709 の動画を BT.601 で読む（実測）。Linux の CI の OpenCV は正しく読む（CI のログで確認）。タグが bt709 の動画は ffmpeg で読むようにした。最初のテストは Windows の挙動を前提にしていて CI で落ちたので外した。
- **3D の試作はリポジトリに入れない**: 作品固有の値が多く、試作の段階なので、スクリプトは Git の外に置く。部品にする価値が見えたら改めて判断する。
- **合否の基準はデータを見る前に固定する**: モデルの判定基準は先に書き、文言を変えない。絵の判定はユーザーが行う。
- **AI 生成のモデルは 1 枚のメッシュ**: 髪・服・体がつながっている。自動リグの重みのままでは踊れず、髪、スカート、胸の帯、UV の継ぎ目の二重頂点を直した。
- **顔は Tripo の形を残して立ち絵を投影する**: 面を強くなめらかにする方法は正面はきれいでも鼻とあごが消えた。ユーザーが「横顔がつぶれている」と指摘して分かった。肌の形を残し、前髪で隠れた目のまわりだけをつなぐ方法に変えた。
- **頭は硬い塊として動かす**: 自動リグはあごを頭の骨に 63% しか付けていなかった（実測）。あごより上を頭の骨だけにして、顔の歪みを 12 mm から 0 mm にした（実測、頭に対する動き）。
- **確認の仕方**: 3 コマだけの確認では、ひねるコマの破れを見落とした。全コマを測ることと、色なしで横から見ることを手順に入れる。
