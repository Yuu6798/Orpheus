==== model3d
usage: model3d [-h] [--version] {demo,dance-recipe,run,accept,edit,manifest,semantic,validate,check,mesh,generate,handoff,rea,blender,frames,ops} ...

self-made 3D modeling tool: recipes, semantic parts, checks, run records

positional arguments:
  {demo,dance-recipe,run,accept,edit,manifest,semantic,validate,check,mesh,generate,handoff,rea,blender,frames,ops}
    demo                write synthetic inputs, preset, semantic map and a recipe
    dance-recipe        connect a private recovered dance worker bundle to RecipeGraph
    run                 execute a recipe and write a run record
    accept              record the human decision for a run
    edit                record a manual edit (what, by whom, minutes) on a run
    manifest            write an AssetManifest for input files
    semantic            build or confirm a SemanticMap, and bind face regions of a mesh version to roles
    validate            validate a file against one of the data contracts
    check               run one check on files
    mesh                convert between model3d-mesh JSON and OBJ, or summarize a mesh
    generate            initial model from a setting sheet: prepare the image or inspect a generated mesh
    handoff             write a handoff record (run, recipe and artifact sha256) for Orpheus
    rea                 turn REA analysis outputs into recipe evidence
    blender             run Blender in the background (unverified on this machine)
    frames              compare two folders of rendered frames (f<T>.png) or two frames lists
    ops                 list the registered operations

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
